# Release traffic comparison progress — 25 September 2026

Monitor deployment detail now compares Analytics outcomes around a recorded deployment when the Monitor environment and Analytics site are explicitly connected to the same Core project with the `traffic_context` capability.

Core resolves only active project mappings and connections. It rechecks the viewer's project membership and Monitor/Analytics product grants, then requires the Analytics `traffic_context` entitlement and the Monitor `deployment_context_minutes` limit. The requested before/after interval is capped by both that plan limit and the elapsed time since the deployment. A disconnected site, revoked grant, missing plan capability, unavailable Analytics database, or absent authorized mapping yields the generic empty state.

Analytics returns processed aggregate counts only: pageviews, distinct non-null visitor hashes, goal conversion events, and distinct converted visits. Conversion records are included only when their linked ingestion batch is processed. When a connection is eligible, Monitor and Analytics use the same UTC before/after boundaries; the Monitor telemetry window is narrowed to respect the connected plans. The page compares Analytics' latest processed-through timestamp with the expected window end, labels missing or lagging processing, and notes that a current timestamp cannot rule out ingestion gaps. It links to the access-checked Analytics site dashboard and lists same-environment incidents overlapping the comparison and other deployments of the same service in those windows. Delays, sampling, visitor mix, and overlapping releases can affect observed differences; the page does not claim causality or expose visitor-level data.

Regression cases were added for plan-bounded windows, explicit connected-site lookup, processed conversion filtering, and converted-visit counting. They are authored and intentionally unrun while the plan remains incomplete.

This advances I5 but does not complete its acceptance gate. Still open: complete coverage accounting that distinguishes missing data from zero activity across the whole window; source-report reconciliation against representative Analytics data; destination-page authorization regression; and complete role, revoked-connection, product-outage, and production-engine acceptance. The deployment view labels UTC explicitly; workspace-local timezone selection is not implemented.
