# Unified platform feature-parity matrix

Prepared 23 September 2026 against the supplied source revisions below. This is an initial capability-level inventory from routes, controllers, models, migrations, jobs, commands, notifications, and configuration. It is a traceability checklist, not proof of behavioral parity: Monitor and Analytics source has been imported into peer modules, Core integration is not live, and workflow-by-workflow evidence still needs to be recorded before cutover.

The counts describe the audited baseline and were produced from route declarations, so they are not unique customer features. Deployer routes, HTTP code, models, actions, jobs, notifications, commands, policies, services, scripts, product views, and migrations now reside under `app/Modules/Deployer`; `database/migrations` and the prior product-view paths remain compatibility symlinks. Shared Signal layouts and UI components remain in `resources/views`. Monitor and Analytics source trees are imported into their modules, but neither is enabled for customer traffic. Module relocation preserves source behavior, but every regression-evidence cell remains open.
